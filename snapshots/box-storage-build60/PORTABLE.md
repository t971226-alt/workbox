# BOX 免安装版

当前版本：1.1.0.52。适用 Windows 10/11 64 位，直接运行 WorkBox.exe，无需安装运行环境。

新建收纳规则可勾选“当前软件名”，自动代入收录确认清单中的软件名称；其他文件名关键词用中文/英文逗号、空格或 + 分隔，必须全部包含，顺序不限。左侧文件类型仍须匹配。多份文件匹配同一项时需明确选择，不默认挑选最新文件。已有规则和任务快照保留原识别方式。

新收录默认直接保存到“所选位置\软件名称”，不再因材料规则自动增加“Word文档”等分类层。需要分类目录时可主动新建或选择保存文件夹。已有任务仍使用原保存位置。

## 新版启动选择

发现已有 BOX 时，可以选择“更新原 BOX”：自动备份并替换原位置程序，继续使用原总表与材料；或选择“独立使用新版”：在当前目录新建空总表，重新设置保存位置，不复制旧数据、设置或历史。独立版后续只打开自身目录，不自动跳转或提示导入旧总表，也不改变原版的默认位置。“暂不使用新版”则继续打开原 BOX。

独立使用要求当前目录没有运行数据；已有数据的目录不会被清空。新建材料文件夹默认只用软件名称；同名任务需要分开保存时，添加首次收录时间，同一秒仍重名时再加序号。更新已有任务沿用其保存目录；历史带 WB 编号的目录保留原位置。

程序工作文件保存在“BOX工作文件（自动管理）”，其中“材料处理区”用于处理任务文件，“导入暂存区”用于暂存待收录文件。旧名称在备份并核验后同步更名，正式材料和历史版本保留。今日收录总览使用淡绿色底色与细边框，适配浅色、深色主题。

## 今日收录

会话上方显示今天收录的材料份数、软件数及各收录规则的分类数量。点击总数或分类，在右侧查看对应文件、收录时间与保存位置；同一任务的同一材料当天更新多次只计一份。输入框仍在会话底部，统计不占用对话滚动区域。删除的任务、异常副本不计入当前统计；日期按北京时间。

## 收录材料

1. 首次选择材料保存目录。拖入文件、文件夹或压缩包，确认软件名称。
2. BOX 按软件分组，每个软件只选一套材料清单；展开后可检查文件、调整对应材料或保存文件名。
3. 新规则按文件类型接收，例如 Word 兼容 DOCX、DOC、WPS、ODT 等；压缩包兼容 ZIP、7z、RAR。任选一种即算一份，保留原有后缀和内容，不转换格式。旧规则仍按原先指定后缀收录。
4. 文件夹名称和保存文件名默认使用软件名称，可以分别修改。手动改名后不再跟随软件名称变化；实际重名的材料会补材料名区分。
5. 点击“确认收录”保存 BOX 副本，来源文件保留。取消不会创建任务或规则。

新规则可按软件名称自动对应材料。拖入“软件名称.docx”和“软件名称_代码 (JavaScript+HTML+CSS).docx”时，可建议“同名 Word＋代码 Word”；换另一软件仍可复用，同类后缀任选一份。PDF、表格、演示、文本、图片、视频、音频、压缩包，以及已支持的其他格式使用同样的匹配方式。显示名称可修改，识别设置单独收起；“软件名称”会自动代入当前软件名，代码标记允许附带语言说明。匹配依据文件名和类型，不代表核验文档内容。

混合拖入压缩包与其他材料时，同一确认清单显示全部文件，压缩包作为原包保存，不自动解压。已有规则中的压缩包材料可直接对应该项；其他原包继续使用原包收录窗口。遇到额外类型，会明确显示本次将新增的材料项，确认后只补充本任务清单，通用规则不变。旧规则、任务快照、目录和历史不自动重写。无后缀文件留在清单中，默认未勾选，需人工核对。

一次拖入多个压缩包时，可使用“保存文件夹”统一选择分组位置，例如 D:\BOX\可运行压缩包。每个软件默认单独建同名文件夹，文件名也默认使用软件名称；可以分别改名或单独跳过。本次选择不改变全局材料保存目录。同名独立任务会区分文件夹，避免混放或覆盖。

压缩包默认“保存原包”，不读取包内材料。需要收录内部文件时再选“解压后分类”：ZIP、7z 可解压分类，RAR 当前支持保存原包。同一材料的多种格式只计一份，默认勾选最近修改的文件，可手动更换。

规则只描述需要哪些材料，不决定文件夹名称。改规则名称不会移动已有文件，既有任务保留自己的材料要求。新建保存文件夹时，可直接添加 Word、压缩包、PDF、表格等类型和份数，也可以在已有清单上补充。多个同类型文件按不同逻辑项计数；同名不同后缀仍作为同一项的候选版本。


新任务默认保存为“保存位置/保存文件夹/软件名称/文件名.原后缀”。不同材料清单分别建议保存文件夹，名称可修改；软件子文件夹、文件名默认使用软件名称。已有任务补录沿用原位置，改变新任务的保存位置或材料清单不会移动旧材料。

“新建保存文件夹”只需填写文件夹名称和要收哪些文件；清单名称按需展开。“记住这套要求”决定是否加入可复用清单，未勾选仍保留当前任务和该文件夹的要求快照。取消确认不建立文件夹配置或正式材料。

## 查看、补交与删除

双击软件查看材料，点击查看文件或打开保存位置；版本历史在详情中展开。待补材料一直保留在“待整理”，不会因跨天消失。收录查询可按日期、分类规则和状态查找，总表可导出。

补交缺少的材料会填入已有任务。已有同名材料时，选择覆盖原任务或新建独立任务；覆盖保留版本历史，新建会区分保存目录。

删除任务默认保留已收录文件，可从“已删除任务”恢复。勾选“同时删除已收录的材料”才会删除 BOX 管理的副本及历史，来源和共用文件受到保护；恢复任务不能找回已删除的文件。

## 保存位置与缓存

拖入后的暂存和新任务工作区跟随选定的材料保存目录；已有正式材料与历史位置保持。存储管理可打开所在位置或清理未引用的过期暂存，任务工作区、正式材料和历史不参与缓存清理。

## 更新

日常使用同一个 WorkBox 文件夹和总表。更新只替换校验清单中的程序文件，先备份总表和旧程序，保留 data、材料及历史。收录进行中不会强制退出；更新失败恢复旧程序。外层原始 ZIP 不随本地维护改动。
