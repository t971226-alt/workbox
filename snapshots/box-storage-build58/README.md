# WorkBox 工作箱

当前免安装版：1.1.0（构建 32）。解压完整的新包后运行 WorkBox.exe，程序会在打开数据前识别已有 BOX：

- 下载的是较新版：核对原位置后选择“备份、更新并打开原 BOX”，更新程序并继续用原来的总表。先完成收录并退出旧版；支持新机制的空闲 BOX 会正常退出，程序不会强制结束工作。
- 下载的是相同版本：直接打开已有 BOX，不在下载目录建立另一份总表。
- 下载的是较旧版：提示打开已有新版，不用旧程序修改新数据。
- 找到多份数据：选择日常位置，其余数据保留，并引导核对导入；不自动合并或覆盖。

程序优先识别已记录的日常位置，也检查常见桌面、下载、邻近目录及已有安装位置；首次找不到时可选“已有 BOX”手动选择原文件夹。更新只替换程序清单中的文件，总表备份保存在原位置的 data/更新备份，材料目录与历史保持；失败恢复原程序，可从下载的新包重试或恢复上次未完成的更新。更新完成后不保留旧程序副本，附加的非程序文件另行保留。

版本识别机制从 1.1.0 开始生效。更早的程序自身没有此检查，请从新版发起接管或导入，不继续直接运行早期副本。日常始终使用同一个目录和同一份总表。识别依据程序文件版本和随包校验清单，不根据文件时间猜新旧，不联网自动下载程序。


WorkBox 是 Windows 本地项目与交付文件管理工具。通过悬浮球打开管理面板，收录项目、整理工作目录并保存交付归档。项目状态包括待开发、开发中、待交付和已交付，紧急标记独立管理。

## 批次材料检查与提交

新增分类使用一页引导：点分类栏“＋”，选择现有模板，改一个名称，点击“创建分类”即可。材料自动填好，也可用“＋ Word / PDF / 视频”添加，材料名称与文件格式分开填写，不必手写后缀。底部实时显示每个软件需要几份材料和收齐条件；识别关键词、启停状态收在高级设置中。新建直接保存，修改已有分类仍显示变更说明。名称重复、材料缺名或重复会就地提示，保存失败保留填写内容。

也可以不预先提供软件名称，直接拖入材料。BOX 根据文件名、目录名及可修改的分类规则显示核对清单，确认后建立同一总表中的任务、分类复制并回填收录状态；“说明书.docx”等泛名文件需补充名称，可批量填写选中行。核对页可更改分类、逐文件材料类型和新批次处理方式，取消不建任务、不收录。分类按当前文件推测，所需数量以确认的清单为准；已有任务保留原要求，同名材料继续提供新建、覆盖或取消。程序不通过读取文档正文猜测软件名称。

主工作台提供“尚未完成”和“已完成查询”：未完成任务跨天保留，完成查询默认显示最近完成日，可用分类、状态、日期及名称筛选。双击软件查看逐份材料；缺项用文件类型图标展示，悬停查看全名。所有任务仍在唯一总表中，“更多 → 材料明细视图”保留原批次展开界面。

主界面已移除处理方式开关，分类规则保留新批次的默认处理方式：**统计整理已完成材料**用于分类备份，收齐即完成；**统计初始未提交材料**保留人工检查和实际提交登记。已有任务沿用原处理方式、版本、检查及提交记录。主工作台“更多”可查看上次收录结果、继续未完成导入和导出当前筛选。会话查询替换旧筛选，其数量与右侧结果一致；“显示全部”包含当前有效的未完成和已完成任务。

分类标签旁“＋ / −”可添加或移除分类，双击标签修改分类规则，右键也可操作；“··· → 管理分类”支持管理全部分类、排序与重新启用。可维护材料文件名、格式、同格式识别关键词和新批次默认处理方式。修改弹窗解释作用范围，保存前列出具体变更。修改只影响新批次；历史使用中的分类删除时改为停用，已有清单、文件夹和完成记录保留。左侧会话支持收起与展开，记住显示状态和宽度，草稿不丢失。

“设置 → 开机自启”可开关当前用户登录启动，默认关闭。开启后下次登录只显示悬浮球和托盘，不弹出主窗口；移动免安装目录后重新开启即可更新启动路径，无需安装或管理员权限。


本工作区版本提供唯一的「软件材料总表」，所有批次的软件名称、收录、检查和提交持续更新在同一表中。一天可以有多个批次，一个批次可以只有一个软件，同批软件也可以有不同材料要求。批次用于文件归属及筛选，不另建独立表格。

1. 完成首次目录设置后，进入左侧会话、右侧总表的工作台。在左下输入框粘贴一批需求，点击「↑」发送；Ctrl＋Enter发送，Enter换行。「＋」可导入 Excel/CSV、识别文件夹或保存模板，也可展开默认归属与套餐。
2. 原文和整理结果直接显示在会话里。每条结果有批次、软件名称、套餐和材料数；「核对清单」打开完整清单编辑，保存后回到同一会话，不建立任务。
3. 核对后点击会话卡片的「确认建表」，将本次名称追加到右侧唯一总表。「查看总表」显示所有批次并定位本次任务；会话不再保留已建任务的独立小表。取消本次建任务也保留原文和清单。只给名称时，先保留待识别；收到名称匹配的成品后按材料职责识别类型。
4. 套餐包括单手册 Word、五件材料、桌面14件、14件＋双视频，以及自定义。每种格式独立计项，例如说明书 Word 与 PDF 分别检查。
5. 将成品文件或文件夹拖进 BOX，按软件名称回填原任务。自动收录到「材料保存目录/单Word、五件材料、14件材料、14件＋视频/本批首个软件名-本批软件数量件」。例如六个名称的第一项为建筑检测管理系统，则目录为「建筑检测管理系统-6件」；即使第三项先收到，仍以第一项命名。单 Word 同批集中存放，多材料按软件分子目录。同名重做目录加「（2）」等序号。点击「收录文件夹」直接查看。
6. 双击历史版本打开文件检查，标记「检查通过」或填写「需要修改」的原因。
7. 实际提交材料后，勾选名称并点击「确认已提交」。也可在材料格内按份确认，整项显示部分提交。
8. 总表以批次和软件分组显示，展开后查看每份材料；导出一行一个软件任务。「修改名称」修改所选任务，身份及记录按任务编号保留，已分配目录名称保持稳定。导出为一份总表 CSV，含日/月字段、收齐/检查/提交日期和收录目录。误记可在材料详情撤销。
9. 总表底部「按天统计/按月统计」和日期选择器显示全表新增、收齐、全部检查通过、全部提交的软件任务数。四项按各自实际日期计算，北京时间；统计当前有效任务与当前版本，改版、撤销会同步重算。统计不受搜索/批次筛选影响。表格可按今天、昨天、本月、上月、最近7天筛选，筛选只改变同一总表的显示范围。
10. 再次拖入已有的同名材料，会弹出「已存在同名文件」。可选「新建」「覆盖」「取消」：新建为下一轮制作，总表新增行，不继承旧确认；覆盖更新所选原任务，旧版本及提交历史保留，变化的材料需重新检查。相同内容选择覆盖会去重。多个批次同名时，可在对话框选择对应任务；文件夹或材料包中同一软件的一组材料一起选择，补交不同材料类型不会重复询问。同一次拖入中新建的多个软件组成一个新批次。

会话原文、修改后的清单、建任务结果和未发送草稿保存在本地。「新会话」保留之前的草稿，顶部历史列表可恢复；长会话可加载更早记录。首次打开不自动建立空任务。同名重做和材料表的需求导入入口也回到会话接收区。导入表格/文件夹后仍需核对确认，收到文件不代表已建任务。

每行对应一个批次中的一次制作任务。同名重新制作请点击「同名重做」，新批次采用独立任务ID和目录；「复用上轮材料」也需要重新检查，不继承旧确认。
内容不变的重复收件不会清除确认；变化的材料生成新版本，仅该类材料回到待检查。归档副本保存旧版，工作目录中已登记材料的内容变化在稳定等待后自动建立新版；等待期间禁止确认过期版本。
说明书或代码 Word 更新时，对应 PDF 显示「待更新」且不再计入当前完成数，旧 PDF 的提交历史仍保留。重新生成、收录并检查 PDF 后可再次提交。

已有批次可用「批次默认材料」启用尚未设置清单的任务，旧文件在材料格内归类，历史检查结果不做推测。每个软件保存独立要求；「本项要求」允许追加、删减和更换套餐，填写原因并保留变更记录。修改批次默认材料不覆盖已有任务要求，删减材料也不删除旧版和历史。
文件夹导入只在核对确认后复制材料；遇到占用或取消，任务和成功文件保留，通过「继续文件导入」重试未完成项。Excel 导入读取当前活动工作表，首行需有“软件名称”；公式需先转换为值，旧 XLS 请先另存为 XLSX。
会话建任务失败后可修改清单重试；任务已落库而后续文件处理中断时保留原任务，通过会话的「继续导入材料」恢复，不重复建任务。
全部识别在本机按明确规则进行，不调用外部 AI 或上传需求。未填写要求的任务按当前已识别职责推定：说明书 Word → 单 Word；出现 PDF、代码或信息表 → 五件材料；出现其余桌面或视频职责 → 14件＋双视频。后续材料可升级推定类型并重新计算缺项。已明确的要求不会被自动替换；如果预先知道应交五件或16件，请在建表时选择套餐，避免仅收到一份 Word 时暂按单 Word 显示收齐。无法识别职责的文件需人工归类，不能只凭文件数量判断套餐。
**清单任务不按 ZIP 文件数自动交付，必须人工检查并记录提交。** 未启用清单的旧任务继续原有模式。
新提交记录与旧「今日交付」历史各自保留；表格勾选只是本次选择。确认仅记录你已完成的提交，不向客户或外部平台发送文件。

双击 `start-workbox.cmd` 直接启动唯一维护的新版免安装 BOX（`dist/total/WorkBox/WorkBox.exe`），不再启动 Python 源码界面。后续修改需同步更新此程序与免安装包。完整任务规则见 [PRODUCTION-WORKFLOW.md](PRODUCTION-WORKFLOW.md)。

## 界面与皮肤

桌面采用左侧 GPT 式会话、右侧 Notion 风格材料总表的常驻分栏，可拖动调整宽度。会话输入名称并核对建表，也支持本地名称、进度、日/月统计查询；结果联动右侧筛选，检查和提交仍在材料操作中确认。输入框旁「＋」集中导入工具，筛选按钮集中进度、日期和批次条件，总表「•••」收纳导出和材料操作。

主工作台采用870×640内容区（含系统标题栏约870×670）的紧凑布局，统一中性灰白表面、细线图标、圆形发送键和30px操作控件。左侧只保留会话记录，不再提供手动新建会话按钮，复制使用重叠方框图标；图标入口均有悬停说明和可访问名称。正文与表格分级排版，名称保持阅读宽度，窄窗口通过横向滚动查看后续列。

桌面右上角“设置 → 外观”可选择浅色、深色或跟随系统。界面、菜单和弹窗使用统一颜色，悬浮球固定白底黑线以保持桌面可见；切换不改变项目、工作目录和交付规则，保留当前选择与滚动。官网及私密统计页也支持三种外观，浏览器偏好与桌面独立保存。

本次更新让长中文项目名与文件名换行显示，按钮在各状态保留完整文字，调整分栏后保持阅读位置。基础按钮、输入框、复选框、数值控件与徽章使用 QFluentWidgets 1.11.3，外观仍由 WorkBox 统一管理；窗口边框、菜单和滚动保留 Qt 原生机制。完整第三方许可随包保留。

## 第一次使用

首次启动只显示一个材料保存目录，点击「开始使用」进入会话与总表。工作设置与使用指南同样只显示材料目录，不再配置或创建额外的 ZIP 归档目录。无需选择工作模式或文件数量门槛；统计初始未提交材料方式下，材料收齐后仍须检查并确认已提交；统计整理已完成材料方式下，收齐即完成备份记录。取消不保存，完成后才开始收件与监视。已经完成设置的用户升级时保留现有目录、历史归档和配置，不重新引导。

“使用说明”只介绍材料录入、收录、检查和提交。设置只提供材料保存位置，不再显示旧项目模式、文件数量门槛或自动交付按钮。

窗口支持拖动边缘、右下角缩放手柄或标题栏最大化按钮调整大小；恢复后保留普通窗口尺寸。悬浮球右键只保留打开 BOX、收录材料、隐藏/显示悬浮球及退出 BOX；托盘提供同一菜单。

## 日常使用

- 在左侧会话录入名称和材料要求，核对清单后追加到唯一总表；Ctrl＋Enter发送，Enter换行。
- 输入框「＋」保留表格导入、从文件夹导入名称和默认材料要求；复制粘贴使用系统快捷键。
- 将成品拖入窗口或点击「收录材料」，按名称分类回填；同名时选择新建、覆盖或取消。
- 右侧搜索名称，筛选按钮选择进度、建表日期、委托或批次；「•••」可导出总表、打开材料文件夹，选中任务后可修改名称或材料要求。
- 双击软件检查具体材料，实际提交后勾选确认。总表底部用「日／月」和日历选择统计范围。
- 设置按钮提供材料保存位置、外观、使用说明、后台运行和退出；普通ZIP库、旧项目管理及自动交付不再作为日常入口。

程序使用本地 SQLite 和文件目录，不提供账号、云同步或远程数据库服务。请自行备份数据与归档文件。
后续更新保留现有 data、工作目录与归档文件，仅维护这一份新版免安装程序。

应用、托盘、悬浮球与官网图标使用用户确认的黑白盒盖＋封口 W 标志，保留加粗线框、中央放大和鱼眼弧面。绘制源为 `orb_artwork.py`，Windows 图标由 `branding.py` 生成；功能图标继续使用 Lucide，完整第三方许可随包提供。
下载站的浏览与下载统计由独立网站服务记录，仅站点所有者登录可见，不收集桌面项目数据。

## 从源码运行

建议使用 Windows x64 与 Python 3.11。技术栈为 Python、PySide6、SQLite 和 PyInstaller。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.\.venv\Scripts\python.exe main.py --panel
```

运行公开测试及生成冻结程序：

```powershell
.\.venv\Scripts\python.exe -m scripts.run_tests -q
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

唯一构建交付目录为 `dist/total/WorkBox`，免安装包为 `dist/BOX-Portable-20261029-Total-x64.zip`。用户数据存在时，在临时目录构建验证再更新此目录的程序文件，保留 data。测试使用隔离夹具，公开测试中的项目名称已匿名化。源码不包含原工作区的操作日志、历史截图或用户数据。

制作安装包需要另行安装 Inno Setup 6。生成安装载荷前，先核对冻结程序摘要；使用 `python -m scripts.build_installer --help` 查看输入参数。安装脚本按当前用户安装，保留运行后创建的数据。

旧记录自动导入：打开“设置 → 导入旧 BOX”，先弹出材料处理方式选择：复制到 BOX（默认推荐，原材料保留），或迁移到 BOX（导入提交成功且校验后移除原材料）。选好后程序会查找常见旧版位置，也会提示当前 BOX 中尚未进入总表的旧项目。找到一份时自动核对，找到多份时先选择；找不到可选择旧版文件夹或 workbox.db。核对项目数、材料和历史记录后，点击“自动备份并导入”。

导入前自动备份新版数据，并保留旧数据库原始副本；复制材料后校验，再合并记录。复制方式保留原材料；迁移方式仅移除旧记录中已登记、已转存且校验成功的材料，不删除旧数据库、不清空目录，其他文件保留。新版已有项目不覆盖。同名旧软件作为独立记录保留，同名批次、分类自动改名；同一份未变化的数据库再次导入不会重复添加。当前 BOX 的旧项目只补建总表材料清单，不重复建立项目。

缺失材料会明确列出，可补充搬迁后的材料位置再次查找；只有主动勾选后才允许部分导入，结果会标明缺失。旧版真实检查和提交记录可保留，旧版“已交付”状态只作为原状态展示，不推测为逐文件检查或提交。旧版后台监控不会自动继续。建议先关闭旧 BOX 再操作；备份和报告保存在 data/旧版导入/导入记录。

迁移前请退出旧 BOX。迁移要求材料齐全，有缺失时先补充位置，或改选复制。原件被占用、发生变化、仍被当前 BOX 使用或副本校验失败时，保留原件并在结果中说明；可在导入结果中点击“继续迁移原材料”重试，不会重复建立项目。已复制的完整导入，在再次选迁移并核对到同份数据后，可明确点击迁移原材料。当前 BOX 内旧记录仅补表和复制整理，不移除正在使用的文件。

右侧统计随处理方式联动：整理方式显示软件总数、待补材料、已整理完成；检查提交方式显示待收齐、待检查、待提交、已提交。可选择全部批次或当前批次，统计受分类、搜索和其他筛选影响。混合方式分别显示两组，整理完成不计作人工检查或提交。点击统计数字筛选对应软件，再点一次或点清除统计筛选可恢复；数字保留原范围的统计基数。日/月按各自完成日期计算当前有效任务，与当前状态分开，改版或撤销会重算。分类标签显示软件数量，批次细条表示当前显示软件的材料收齐比例，提交另行登记。文字用原生控件显示，图片预览缩放可能显得发虚。
