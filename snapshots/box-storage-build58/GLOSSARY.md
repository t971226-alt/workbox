# BOX 制作与交付

BOX 按需求归属组织软件制作，逐份检查并记录交付结果。

## 语言

**需求会话**：用于持续接收原始需求、核对清单并查看建任务结果的工作上下文。一个会话可以处理多个批次，会话本身不等于批次。

**整理清单**：从一次输入或导入中整理出的待核对软件名称与材料要求；确认建立任务前不算制作任务。

**委托项目**：同一客户或同一项委托的可选归属，可以包含多个收件批次。
_避免_：用项目同时指代委托和单个软件。

**收件批次**：一次收到并一起安排的一组制作需求，可以只包含一个软件任务；一天可以有多个批次。
_避免_：按日期强制合并的日批次。

**软件制作任务**：某个软件名称在某批次中的一次制作，有独立的材料要求、检查和提交记录。
_避免_：把同名软件的所有制作轮次当作同一任务。

**软件分类**：描述软件业务领域的标签，可跨委托项目和批次使用。
_避免_：用软件分类代替收件批次或材料套餐。

**材料套餐**：一组可复用的交付要求；选择后成为本次任务的要求，不随模板后续变化自动修改。

**交付项**：本次任务明确要求的一份材料，职责与格式共同确定身份，例如说明书Word与PDF分别计项。

**材料版本**：某个交付项的一次内容快照，检查和提交结果均属于具体版本。

**提交确认**：用户记录已经执行的外部提交动作，不代表BOX向外发送了文件。

**分类收录**：将名称匹配的当前材料版本复制到「材料类型/批次/软件」目录；单 Word 同批直接集中在批次文件夹。

**收录结果**：已收齐、部分收录或未收录，按本任务当前要求计算；与检查和提交独立。待识别任务的自动套餐会随新职责出现升级，人工明确要求后停止自动替换。

**软件材料总表**：所有批次共用的持续更新清单，一行对应一个软件制作任务；筛选不创建新表，导出一份全量CSV。同名重做按不同任务编号保留独立行。

**日/月统计**：按北京时间统计当前有效任务的新增、全部收齐、全部检查通过、全部提交数量，各项归入自己的实际发生日期；改版或撤销后重算当前有效结果。
