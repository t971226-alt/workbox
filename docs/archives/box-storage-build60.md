# BOX 第60版源码与程序快照

本分支保存 BOX 材料收纳版 1.1.0.60。源码在 `snapshots/box-storage-build60/`，421个源码文件及逐文件 SHA-256 清单原样保存。原项目 main 与第54、58版发布保留。

## 下载与运行

在 Releases 下载 `box-storage-build60-20261104` 的 `BOX-1.1.0.60-Portable-Windows-x64.zip`，完整解压 WorkBox 文件夹后运行 WorkBox.exe。源码另附 `BOX-1.1.0.60-Source.zip`，两份归档的摘要见 `SHA256SUMS.txt`。要使用空白环境时选择独立运行；更新原 BOX 时保留总表、材料及历史。

包内不含用户总表、材料、个人设置、导入清单、日志和备份。保留 GPL 与第三方许可。此发布归档已构建的本地程序，程序早于本次源码快照提交构建；不声称由此提交重新构建或已验证可复现构建。

## 相比第58版的变化

- 主界面新增“导入表格”，支持 XLSX、CSV、TSV 名称清单核对；旧 XLS 需另存为 XLSX。
- 自动建议软件名称列与日期列，保留合并日期、多行名称和重复记录。支持全部日期、某一天及包含起止日的时间段筛选；只导入选中范围，不改原表日期。
- 清单独立于已有任务保存；核对不创建任务、不更改规则或材料。同名多任务需确认，避免静默合并。
- 总览采用紧凑的日期与软件名称左右双栏。材料不齐、未收录用不同底色；双击查看详情，保存路径后的小文件夹图标打开实际保存目录。
- 悬浮球角标使用与“待整理”一致的未完成口径，收齐后无需提交即可退出角标计数；左右半隐藏时角标留在屏幕内侧。
