# BOX 第58版源码与程序快照

本分支保存 BOX 材料收纳版 1.1.0.58。源码在 `snapshots/box-storage-build58/`，417个源码文件和逐文件 SHA-256 清单原样保存。原项目主分支和第54版归档不变。

## 下载与运行

在 Releases 中下载 `box-storage-build58-20261103` 的 `BOX-1.1.0.58-Portable-Windows-x64.zip`，解压完整 WorkBox 文件夹后运行 WorkBox.exe。源码单独提供 `BOX-1.1.0.58-Source.zip`，两个文件的 SHA-256 见 `SHA256SUMS.txt`。首次启动选择独立运行，可使用空白数据环境。

程序包不含用户材料、总表、设置、日志和维护备份。保留 GPL 与第三方许可。此版本是已验证本地构建的归档预发布；程序早于本次源码快照提交构建，不声称从此 Git 提交重新编译或已经验证可复现构建。

## 主要变化

- 未匹配的文件统一提示新建规则并选择保存文件夹，确认前阻止漏收。
- 新规则从本次文件类型和关键词预填，必须选择真实文件夹；规则与目录绑定一起保存，失败一起回滚。
- 保存后仅重新匹配当前软件；已有规则、目录绑定和历史任务保留。已有同名任务时，本次另建收录记录。
- 同名材料支持保存为新版本、直接覆盖旧版本、另存为独立副本和本次跳过。
- 收录确认和材料详情采用紧凑布局，规则管理与文件夹管理保持独立入口。
